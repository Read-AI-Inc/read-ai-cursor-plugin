# Install Read AI MCP

Remote endpoint: `https://api.read.ai/mcp` (Streamable HTTP + OAuth).

Exact config keys vary by client (see `CLIENTS.md`). In the client’s remote MCP UI, add that URL, then:

1. Complete OAuth with a Read AI account when prompted.
2. Confirm at least one tool appears (for example `list_meetings`).

No local install or API key is required for OAuth clients.
